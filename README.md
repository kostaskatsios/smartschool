# Δημιουργός Παραμυθιών

Αυτό το μικρό εργαλείο τερματικού δημιουργεί παραμύθια τύπου storybook για μικρά παιδιά. 
Ο χρήστης ακολουθεί μια διαδραστική διαδικασία:

1. Επιλογή ανάμεσα σε τρεις βασικές ιδέες ιστοριών.
2. Επιλογή ενός ήρωα/πλοκής με περιγραφή δύο έως τριών προτάσεων.
3. Επιλογή ενός από δύο στυλ εικονογράφησης, μαζί με αυτόματα παραγόμενες εικόνες προεπισκόπησης.
4. Παραλαβή του τελικού παραμυθιού σε μορφή storybook.

## Προαπαιτούμενα

- Python 3.10 ή νεότερη έκδοση
- Εγκατάσταση των εξαρτήσεων από το `requirements.txt`

```bash
pip install -r requirements.txt
```

## Εκτέλεση

Τρέξτε το κύριο πρόγραμμα:

```bash
python -m storybook_app.main
```

Κατά την επιλογή στυλ εικονογράφησης δημιουργούνται εικόνες προεπισκόπησης στον φάκελο `previews/`.
